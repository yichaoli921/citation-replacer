# 《经济地理》引用工作流输出契约

适用于用户要求按《经济地理》或类似中文地理/经济期刊顺序编码制整理引用时。目标是稳定生成三类 Markdown 中间稿，避免只在最终 docx 中“看似完成”。

## 1. 样文风格备忘

文件名建议：`tmp_经济地理文献引用风格.md`

生成时机：用户提供目标期刊最新样文 PDF 后，先把每篇 PDF 转为 `.md`，再人工/脚本抽取引用样例。

必须包含：

- `依据样文`：列出两篇样文 PDF 原路径和转换后的 `.md` 路径。
- `文内引用`：说明是否为顺序编码制、方括号形态、连续/非连续编号写法、叙述式引用写法。
- `文末排序`：说明文末参考文献是否按正文首次出现顺序。
- `中文期刊论文格式`：作者截断规则、作者后空格、文献类型、年份卷期页码格式。
- `英文期刊论文格式`：英文作者写法、`et al.` 规则、题名大小写、期刊名写法。
- `报告/工作论文格式`：`［R］` 模板。
- `后续处理规则`：去重、编号、脚注/资料来源边界、补全核对字段。

风格判断不能只凭记忆。即使已有内置《经济地理》风格，也要优先以用户本轮下载的两篇最新目标期刊文章为准；若新样文与内置规则冲突，在备忘中标注“本轮样文采用 ...”，并按本轮样文执行。

## 2. 正文替换对照表

文件名建议：`tmp_经济地理文献引用.md`

生成时机：从正文 `.docx` 转出的 `.md` 抽取所有作者-年份引用后，按正文首次出现顺序整理。

必须包含两个表：

### 一、正文替换对照表

字段：

| 顺序号 | 原作者-年份引用 | 正文编号式引用 | 补全状态 |
|---:|---|---|---|

要求：

- 同一文献多次出现只分配首次编号，后文沿用。
- 明确记录删除、合并、改引、年份修正，例如 `77 → 76`、`Castells，1999 → 1996`。
- OCR/作者/年份存疑不能静默修正，必须在 `补全状态` 或备注里写出依据和是否经用户确认。

### 二、正文综合引用替换表

字段：

| 正文位置 | 原综合引用 | 建议替换为 | 备注 |
|---|---|---|---|

要求：

- 连续编号合并为 `［1-3］`。
- 非连续编号用中文逗号，如 `［3，15，61-64］`。
- 默认按编号升序合并；若为了保留原叙述顺序另有写法，在备注中给出备选。
- 缺逗号、额外空格、OCR 误字等原文问题写进备注，方便替换脚本和人工复核。

### 三、文末参考文献

在同一文件后部可附最终参考文献，也可以另存为 `refs.tsv` 供 docx 脚本使用。无论哪种形式，编号必须与前两个表一致。

## 3. 参考文献风格与等级稿

文件名建议：`tmp_参考文献_经济地理风格.md`

用途：面向人工核对和汇报，除完整参考文献条目外，还要自动标注期刊等级、补全状态和存疑点。

每条期刊文献格式：

```text
［1］ 黄蕙萍，缪子菊，袁野，等 . 生产性服务业的全球价值链及其中国参与度［J］. 管理世界，2020，36(9)：82 - 97.
- **期刊等级**：A+级（《管理世界》）
```

若期刊不在目录中：

```text
- **期刊等级**：未在西财目录中（《Journal Name》）
```

若非期刊文献，如专著、报告、工作论文，不要硬套期刊等级；可写：

```text
- **说明**：非期刊文献，不标注期刊等级
```

期刊等级来源：`references/journal-levels/swufe_2018.tsv`，即西南财经大学学术期刊等级分类目录（2018 版）。使用脚本：

```bash
python scripts/enrich_journal_level.py tmp_参考文献_经济地理风格.md tmp_参考文献_经济地理风格.md
```

如果直接覆盖同一 Markdown 文件，先备份或输出到临时文件确认无误后再覆盖。

## 4. 必查错误

生成上述三个文件后，必须检查：

- PDF 样文均已转换为 `.md`，且风格备忘列出了 PDF 与 MD 路径。
- 正文 `.docx` 也已转换为 `.md`，引用抽取来自 MD，而不是只凭 docx 视觉阅读。
- `tmp_经济地理文献引用.md` 的最大编号、去重后参考文献条目数、docx 文末参考文献条目数一致。
- 叙述式引用已单独扫描：`作者（YYYY）` 要改成 `作者［N］`，不上标。
- 无卷号期刊格式为 `2025(4)：`，不能写成 `2025，(4)：`。
- 投稿版 DOI 默认删除；仅 `［J/OL］` 网络首发或编辑部明确要求时保留。
- 通讯地址、作者单位、地图来源、数据来源、网址、邮箱不得作为参考文献引用替换。
